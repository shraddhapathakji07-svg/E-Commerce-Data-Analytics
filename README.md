# E-Commerce Data Analysis Using Python

## 📌 Project Overview

This is my first Data Analytics project, where I analyzed e-commerce and sales data using Python.

The project focuses on exploring sales performance, product categories, pricing, purchase frequency, and order-level performance through data analysis and visualization.

The analysis was performed using Jupyter Notebook and Python libraries such as Pandas and Matplotlib.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze revenue generated by different product categories
- Understand product purchasing patterns
- Identify the relationship between product price and purchase frequency
- Calculate and compare order-level rates/revenue
- Rank orders based on their generated rate
- Represent analytical findings using visualizations

---

## 🛠️ Technologies & Tools Used

- **Python**
- **Pandas**
- **Matplotlib**
- **Jupyter Notebook**
- **CSV Datasets**

---

## 📊 Analysis Performed

Some of the questions explored in this project include:

### 1. Average Revenue by Product Category
Analyzed the average revenue contributed by each product category and represented the results using a pie chart.

### 2. Product Price vs Purchase Frequency
Explored the relationship between product price and the number of times a product was purchased and visualized the results using a bar chart.

### 3. Order Rate Analysis
Calculated the total rate generated by each order and ranked the orders based on their rate.
